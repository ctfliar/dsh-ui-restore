## 通用方法（本知识库的骨架）

1. **先确认输入模态**：需要「看图」的任务，先确认模型路由声明了 `image`；DSH 里这是每个模型的 `inputModalities` 配置，不是模型名自带。
2. **风格提取要取全**：底色、圆角、阴影、标签字号、商品占比，和「画了什么」一样重要。只看透明物件会漏掉底卡。
3. **生成与排版分离**：图像生成负责商品与底色；文字标签用 HTML/SVG 叠加，避免生成模型写错字。
4. **生成必须目检**：结构指标（对齐、裁切、溢出）不能替代视觉判断；每页截图逐张看，再决定重生成。
5. **提示词要写「负向约束」**：无底座、无棚拍地板、无背景板、无文字、edge-to-edge 纯色底，比只说「pastel background」有效。
6. **版本隔离**：旧版设计删除或归档，避免和最终版混淆；每次生成记录额度消耗。
